# v1.05-alpha Update Log

Baseline used for this summary: the `v1.04-alpha` tag at `58366e5` from 2026-07-06.

Current endpoint used: `8c8f2de` from 2026-08-08, the commit labeled `perf(solver): precompute least-squares gradient geometry`.

Note: there is no `v1.05-alpha` git tag at this endpoint, so this log summarizes the current development snapshot after v1.04-alpha.

## Highlights

- Reworked the interface around a cleaner application-wide ribbon, centralized units, simplified setup panels, a dedicated Advanced Options window, improved console behavior, and more consistent icons and controls.
- Added multi-block structured meshing for rectilinear sketches, together with shared finite-volume mesh data and expanded aspect-ratio, orthogonality, and skewness inspection tools.
- Added transient solves with first- or second-order implicit time stepping, pulsatile inlets, cooperative stopping, animation capture, playback, and MP4 or PNG-sequence export.
- Added geometric multigrid for the pressure-correction equation, graph-colored Gauss-Seidel for every mesh type, and CUDA graph replay.
- Completed a major CUDA optimization pass that reduced kernel-launch overhead, consolidated face-based execution, fused transport assembly, and precomputed frequently reused mesh and gradient geometry.
- Added complete OpenFOAM case export for multi-block and unstructured meshes, NumPy solution export, and validation tools for Hagen-Poiseuille flow, OpenFOAM comparisons, and the FDA benchmark-nozzle PIV data.
- Added a substantially improved 3D results camera with turntable and arcball modes, orthographic and perspective projection, axis gizmos, standard views, self-framing, and rotation about the model.
- Added results persistence in project files, transient animation restoration, derived velocity-magnitude and cell-Reynolds-number fields, and full-cross-section mirroring.
- Corrected important concentration, radial-momentum, pressure-outlet, fully-developed-inlet, and energy-residual issues. Results produced before these corrections should be re-run.
- Added experimental Linux build and packaging support and made clean builds more reliable on both Windows and Linux.

## User Experience And Interface

- Moved viewport tools into one context-sensitive ribbon above the dockspace instead of maintaining separate toolbars inside each view.
- Added named ribbon groups and a larger, more consistent icon set for menu items, property headers, sketch tools, mesh tools, results navigation, and boundary types.
- Centralized unit selection under **Edit > Units**. Values remain stored internally in base SI units while the interface converts them to the selected display units.
- Added a persistent status-bar readout for the active project length unit.
- Fixed the Units modal so choosing one unit no longer closes the entire window while several units are being edited.
- Simplified and combined setup-tree nodes and property panels to reduce navigation depth and duplicate controls.
- Added **Advanced Options**, with organized pages for solver relaxation, multigrid, residual definitions, non-orthogonal correction, animation limits, and camera behavior.
- Added **Simple View**, which hides the setup panels, console, ribbon, and status bar so the current viewport fills the window.
- Made property tables auto-fit their contents, preventing longer labels such as static-temperature and number-format controls from being clipped.
- Improved console autocomplete behavior, focus handling, keyboard navigation, and command-entry interaction.
- Added safer new-project handling so creating a project resets geometry, mesh, solver, and results state without discarding an unnamed project if Save As is canceled.
- Show the sketch grid and mesh overlay by default so the primary visual context is present when those views open.
- Fixed the empty Advanced Options submenu and converted it into a directly selectable menu item.

## Geometry And Sketching

- Added copy and paste for selected sketch entities.
- Added two-point and coordinate-based movement for selected entities, including live previews, snapping, and undo support.
- Added selection and deletion of sketch entities directly from the Geometry panel.
- Added configurable Ctrl-snap targets through the keyboard/snapping settings.
- Removed the infinite axis lines from snap candidates while keeping the origin, grid, vertices, and geometry available for snapping.
- Improved shared rectangle, arc, translation, and entity-removal helpers so editing, drawing, trimming, and selection use the same geometry rules.
- Fixed trimming behavior, including arcs that cross zero degrees and geometry cleanup after entity deletion.
- Fixed stale property-row change reporting and stranded dimension-label drags when switching tools.
- Display geometry-list coordinates in the active project length unit instead of raw base-SI values.
- Added validation that rejects sketches extending below `r = 0`, where an axisymmetric revolve would be invalid.

## Meshing And Mesh Inspection

- Added conformal multi-block structured meshes for axis-aligned rectilinear sketches.
- Added trellis decomposition using shared axial and radial bands so adjacent structured blocks have matching cell counts and no hanging nodes.
- Added multi-block support throughout mesh construction, boundary assignment, solving, result resampling, inspection, saving, and loading.
- Added a fallback to the rasterized structured-grid path when a sketch cannot be represented as axis-aligned multi-block geometry.
- Added region-of-influence controls that can override boundary spacing within the refinement region.
- Added a far-field boundary type and corresponding UI icon.
- Corrected displayed mesh cell and node counts.
- Reworked boundary-group ID allocation to use a monotonic counter, preventing regenerated groups from accidentally reusing stale IDs. Older project files are migrated on load.
- Consolidated all consumers around one cached `FVMesh` instead of rebuilding separate finite-volume meshes for the solver, results, inspectors, and exporters.
- Added one shared welded cell-corner store for structured, multi-block, and unstructured cells.
- Added mesh-quality calculations and color overlays for aspect ratio, non-orthogonality, and skewness, with consistent legends and per-cell inspection details.
- Improved mesh picking, boundary selection, group editing, band controls, cell outlines, and quality inspection across all mesh types.
- Removed the inactive/solid-cell mask from the solver-side mesh. Only real finite-volume cells are now sent through the face-based solver path.

## Solver, Physics, And Numerics

- Corrected concentration convection so it uses volumetric face flux instead of multiplying the momentum mass flux by density a second time. Concentration solutions from earlier versions should be discarded and re-run.
- Restored the cylindrical `mu*v/r^2` contribution in the radial-momentum equation.
- Applied the Rhie-Chow pressure contribution on fixed-pressure boundary faces, making the face flux consistent with the pressure-correction equation for pressure-driven cases.
- Corrected fully-developed inlet handling so the prescribed profile reaches face interpolation, convection, gradient evaluation, and mass-flux construction instead of only the diffusion assembly.
- Fixed the energy-residual configuration key so temperature residuals are reduced, plotted, and included in the convergence test when energy solving is enabled.
- Added transient SIMPLE solves with backward-Euler and BDF2 time discretization.
- Added sinusoidal pulsatile velocity inlets with phase preserved across continued transient runs.
- Added cooperative stopping so a long transient solve can be interrupted without discarding the partial solution.
- Added configurable keyframe capture and a cap on the transient frames retained in memory.
- Added geometric multigrid V-cycles for the pressure-correction equation.
- Extended multigrid from structured grids to multi-block and unstructured meshes through graph-based coarsening and shared CSR connectivity.
- Added graph-colored red-black/multicolor Gauss-Seidel for all mesh types.
- Hardened multigrid allocation, zero-diagonal handling, coarse-operator construction, and cleanup between repeated solves.
- Removed the obsolete Jacobi-PCG solver path.
- Consolidated duplicated solver choices into `ConfigSolver`, preventing the GUI, runtime, and saved `.axislv` payload from carrying conflicting copies.
- Added compatible migration for older solver payload layouts after the configuration structs and enums were reorganized.
- Added velocity magnitude and cell Reynolds number as derived result fields.

## Solver Performance And CUDA Optimization

- Forced hot per-face CUDA helpers to inline across translation units and changed large device arguments to `const&`, eliminating local-memory spills in the pressure-correction assembly.
- Fused weighted-Jacobi smoothing with residual evaluation and used ping-pong buffers between multigrid levels.
- Captured complete multigrid V-cycles as CUDA graphs and replayed them during SIMPLE iterations instead of launching each small kernel separately.
- Improved transient convergence handling and reduced redundant gradient work during the solver loop.
- Captured linear-solver execution per field so graph state and field-specific buffers are not incorrectly reused across equations.
- Consolidated structured, multi-block, and unstructured execution around the same face-based coefficient path.
- Precomputed face centers, normals, areas, owner/neighbor geometry, and other values reused during assembly.
- Removed repeated runtime geometry validity checks after validating the mesh during construction.
- Added direct cell-face-to-CSR-slot mappings so neighbor coefficients are written without searching a row for the matching cell.
- Fused diffusion and convection coefficient assembly into one transport pass over each cell's faces.
- Cached inverse matrix diagonals for iterative solves instead of repeatedly dividing by the same coefficients.
- Cached reciprocal cell-to-cell and cell-to-face distances used by diffusion and interpolation.
- Precomputed the geometry terms used by least-squares gradients.
- Improved resource-path resolution, precompiled-header coverage, and CMake organization to reduce startup and build overhead.
- In the documented July profiling pass, these changes reduced one representative solve from approximately 11.9 seconds to 5.97 seconds. The later August geometry, CSR, fusion, and caching work builds on that pass; results will vary by mesh, case, and GPU.

- Added velocity-magnitude and cell-Reynolds-number fields to the result-selection workflow.
- Persisted solutions, display state, and captured animation frames in `.axi` project files, rebuilding GPU/render resources safely after load.
- Added compatibility and bounds checking for projects saved during earlier results-format iterations, preventing malformed length fields from causing large allocations or startup crashes.
- Added a 3D corner axis gizmo with clickable standard-axis snapping.
- Added turntable and arcball camera modes, saved per project.
- Added orthographic and perspective projection with consistent apparent framing.
- Changed camera rotation to orbit around the model rather than the viewport center.
- Added front, back, left, right, top, and bottom view buttons, origin axes, keyboard orbit controls, and automatic framing after result generation or load.
- Improved camera panning, pivot tracking, clipping planes, axis-snap interpolation, and unstructured-mesh framing.
- Fixed see-through or missing portions of revolved result surfaces caused by inconsistent face winding and global back-face culling.
- Fixed colorbar handling of non-finite values, tick precision, double-precision tick interpolation, and visible-cell range calculation.
- Moved the colorbar onto the inspector and improved field-tab synchronization after generating or loading results.

## Export, Verification, And Validation

- Added **Export > Solution** support for NumPy `.npy` arrays plus `meta.json`, including cell geometry, solved fields, and transient frames in base SI units.
- Added welded point and cell-connectivity arrays so exported structured, multi-block, and unstructured solutions can be plotted and integrated on the actual solved mesh.
- Added analytic Hagen-Poiseuille validation that separates discretization error, flow-rate agreement, and inlet-boundary fidelity.
- Added complete OpenFOAM case export for multi-block structured meshes, including `blockMeshDict`, initial fields, fluid properties, `controlDict`, `fvSchemes`, and `fvSolution`.
- Added direct OpenFOAM `constant/polyMesh` export for revolved unstructured triangular meshes.
- Map AxiSim boundary groups, field selections, fluid properties, relaxation values, transient settings, and supported discretization choices into runnable OpenFOAM cases.
- Added explicit export diagnostics where stock OpenFOAM cannot reproduce an AxiSim feature exactly, such as pulsatile inlets or kinetic concentration wall conditions.
- Fixed multi-block vertex welding so exported blocks share internal faces instead of becoming disconnected regions.
- Fixed patch classification, fully-developed inlet export, solver-method reporting, non-orthogonal-corrector export, and concentration naming (`Conc`, because OpenFOAM reserves `C`).
- Routed WSL file dialogs through `\\wsl.localhost` paths and streamed exporter diagnostics into the application console.
- Added Python comparison tools that pair AxiSim and OpenFOAM cells spatially, report per-field L2/L-infinity differences, remove arbitrary pressure datums, and plot AxiSim, OpenFOAM, and difference maps on shared scales.
- Added comparison against the five-laboratory FDA benchmark-nozzle PIV dataset at throat Reynolds number 500.

- Added file-kind-specific extensions: `.axi` for projects, `.axigeom` for geometry, `.aximesh` for meshes, and `.axislv` for solver settings. Legacy `.bin` files remain available through secondary filters.
- Added standalone geometry import and export through the File menu.
- Added solution and animation persistence inside project files.
- Deferred OpenGL texture and render-data reconstruction until the GUI context exists when a project is loaded at startup.
- Added file-version migration and stronger bounds checks for strings and containers in binary payloads.
- Rebuilt derived multi-block and finite-volume state after loading instead of serializing duplicate mesh data.
- Saved camera rotation and projection settings with project state while retaining defaults for older files.

- Added v1.05-alpha manual source, updated screenshots, and refreshed supporting documentation.

## Important Corrections And Compatibility Notes

- Re-run concentration cases produced before `fe2c334`; their convective balance used an extra density factor.
- Re-run cases sensitive to radial velocity, pressure outlets, or fully-developed inlet flow because those solver paths received numerical corrections during this cycle.
- Projects and solver files from earlier alpha versions remain available through legacy filters and targeted migrations, but the binary formats are still under active development.
- The OpenFOAM exporter supports multi-block structured and unstructured finite-volume meshes. Unsupported AxiSim-only physics are exported using documented approximations and console warnings.
- Linux support is experimental. Linux MP4 export and image clipboard copying are not currently implemented; PNG-sequence export is available.
- The performance measurements in this log describe one development case on one GPU and should not be treated as a general benchmark.
