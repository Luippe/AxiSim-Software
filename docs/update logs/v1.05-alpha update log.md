# v1.05-alpha Update Log

Covers everything between the `v1.04-alpha` tag (6 July 2026) and 10 August 2026. There is no `v1.05-alpha` tag yet, so this describes the current development snapshot rather than a released build.

## Highlights

- A reworked interface built around one application-wide ribbon, with unit selection in a single place, simpler setup panels, and a dedicated Advanced Options window.
- Multi-block structured meshing for rectangular sketches, plus new tools for inspecting mesh quality.
- Time-dependent (transient) solves, pulsatile inlets, animation playback, and MP4 or PNG export.
- A much faster solver. A representative case went from about 11.9 seconds to under 6.
- OpenFOAM and NumPy export, and validation against analytic pipe flow, OpenFOAM, and the FDA benchmark nozzle.
- A rebuilt 3D results camera with turntable and arcball modes, orthographic and perspective views, standard view buttons, and automatic framing.
- Results now save with the project, including transient animations.
- Several important physics corrections. **Results produced with earlier versions should be re-run** — see the compatibility notes at the end.
- Experimental Linux support.

## Interface

- Viewport tools now live in one ribbon above the workspace, which changes with the active tab, instead of a separate toolbar inside each view.
- Units are selected in one place, under **Edit > Units**. Values are stored in SI internally and converted only for display. The active length unit is shown in the status bar.
- Added **Advanced Options**, grouping solver relaxation, multigrid, residual definitions, non-orthogonal correction, animation limits, and camera behaviour onto organized pages.
- Added **Simple View**, which hides the panels, console, ribbon, and status bar so the viewport fills the window.
- Setup trees and property panels were combined and shortened, so there is less navigating and fewer duplicate controls.
- Property tables size themselves to their contents, so longer labels are no longer cut off.
- Better console autocomplete, focus handling, and keyboard navigation.
- Creating a new project now resets geometry, mesh, solver, and results properly, and no longer discards an unnamed project if Save As is cancelled.
- The sketch grid and mesh overlay are shown by default.
- Larger, more consistent icons throughout.
- Choosing a unit no longer closes the Units window while others are still being edited.

## Geometry and Sketching

- Added copy and paste for selected sketch entities.
- Added two-point and coordinate-based movement, with live preview, snapping, and undo.
- Sketch entities can be selected and deleted directly from the Geometry panel.
- Ctrl-snap targets are now configurable. The infinite axis lines were removed as snap candidates; the origin, grid, vertices, and geometry remain.
- Coordinates in the geometry list are shown in the project's length unit instead of raw SI values.
- Sketches extending below `r = 0` are rejected, since an axisymmetric revolve would be invalid there.
- Fixed trimming, including arcs crossing zero degrees, and cleanup after deleting entities.

## Meshing

- Added multi-block structured meshes for rectangular, axis-aligned sketches. Blocks share axial and radial grid bands, so neighbouring blocks always have matching cell counts along a shared edge and there are no hanging nodes.
- Sketches that cannot be represented this way fall back to the older uniform grid automatically.
- Multi-block meshes are supported everywhere: meshing, boundary assignment, solving, results, inspection, saving, and export.
- Added mesh-quality measures and colour overlays for aspect ratio, non-orthogonality, and skewness, with per-cell inspection details.
- Region-of-influence controls can now override boundary spacing inside the refinement region.
- Added a far-field boundary type.
- The solver, results, inspectors, and exporters now share one mesh instead of each rebuilding its own.
- Corrected the displayed cell and node counts.
- Boundary group IDs are allocated from a counter that never reuses a number, so regenerating a group cannot collide with an existing one. Older projects are migrated when loaded.
- Improved mesh picking, boundary selection, group editing, and cell outlines across all mesh types.

## Solver and Physics

Corrections:

- Fixed concentration transport, which was applying density twice.
- Restored the cylindrical radial-momentum term that had been left out.
- Fixed flow through fixed-pressure boundaries, which did not previously agree with the pressure equation.
- Fixed fully-developed inlets, where the prescribed profile only reached part of the calculation.
- Fixed temperature residuals, which were not being plotted or included in the convergence check when energy solving was on.

New capability:

- Added time-dependent solves, with a choice of first- or second-order implicit time stepping.
- Added sinusoidal pulsatile velocity inlets. The phase carries over correctly when a run is continued.
- A long run can now be stopped part-way without losing the partial solution.
- Added configurable keyframe capture, with a limit on how many frames are held in memory.
- Added multigrid for the pressure equation, which works on every mesh type.
- Added velocity magnitude and cell Reynolds number as result fields.
- Solver settings that were previously duplicated are now stored once, so the interface, the running solve, and the saved file can no longer disagree.
- Removed the obsolete Jacobi-PCG solver.

## Solver Performance

- Cut the overhead of running the solver on the GPU, which was a large share of the total time on smaller cases.
- Multigrid cycles now replay as one recorded sequence instead of many separate steps.
- Mesh geometry that used to be recalculated every iteration is computed once and reused.
- Diffusion and convection are assembled in a single pass over each cell.
- All mesh types now run through the same solver path.
- In the July profiling pass these changes took a representative solve from about 11.9 seconds to 5.97. Later work builds on that. Results vary by mesh, case, and GPU.

## Results and Visualization

- Transient runs capture animation frames, which play back with either a single colour range for the whole run or a per-frame range.
- Added MP4 and PNG-sequence export.
- The 2D inspector can mirror the solved half-plane across the axis, showing the full cross-section.
- Solutions, display state, and animation frames are saved in the project file and restored on load.
- Added a 3D corner axis gizmo with clickable axis snapping.
- Added turntable and arcball camera modes, saved per project, plus orthographic and perspective projection.
- The camera now orbits the model rather than the centre of the viewport.
- Added front, back, left, right, top, and bottom view buttons, origin axes, keyboard orbit controls, and automatic framing after a solve or load.
- Fixed see-through patches on revolved result surfaces.
- Fixed colourbar handling of non-finite values and tick precision, and moved the colourbar onto the inspector.

## Export and Validation

- Added **Export > Solution**, writing NumPy `.npy` arrays plus a `meta.json` describing them. Includes cell geometry, solved fields, and transient frames, all in SI units.
- The export carries real cell outlines, so results can be plotted and integrated on the mesh that was actually solved, not an approximation of it.
- Added complete OpenFOAM case export for both multi-block and unstructured meshes — mesh, initial fields, fluid properties, and the control and scheme dictionaries, ready to run.
- Boundary groups, field selections, fluid properties, relaxation values, transient settings, and discretization choices are all carried across.
- Where OpenFOAM cannot reproduce an AxiSim feature exactly — pulsatile inlets, kinetic wall conditions — the export says so in the console rather than silently approximating.
- Added validation against analytic Hagen-Poiseuille pipe flow, separating discretization error, flow-rate agreement, and inlet fidelity.
- Added Python tools that compare an AxiSim and an OpenFOAM run cell by cell and plot both alongside their difference on a shared scale.
- Added comparison against the five-laboratory FDA benchmark-nozzle PIV dataset at throat Reynolds number 500, in both the sudden-expansion and conical-diffuser flow directions.

## Files and Projects

- Each file kind now has its own extension: `.axi` for projects, `.axigeom` for geometry, `.aximesh` for meshes, and `.axislv` for solver settings. Older `.bin` files still load.
- Geometry can be imported and exported on its own from the File menu.
- Solutions and animations are stored inside project files.
- Multi-block and finite-volume data are rebuilt on load rather than stored, so project files stay smaller.
- Camera rotation and projection settings are saved with the project.
- Added stronger bounds checking when reading project files, so a truncated or corrupted file reports a problem instead of crashing.

## Build and Packaging

- Added experimental Linux x86-64 build, launcher, and packaging support, with setup instructions in `docs/linux-build.md`.
- Added CMake presets and a vcpkg manifest. The old Visual Studio project files were removed; CMake presets are now the only supported configuration.
- ImPlot is vendored, so a fresh clone builds without extra downloads.
- On Windows, dependency builds moved to a shorter path to avoid path-length failures.
- Removed tracked profiler output, backup files, generated videos, unused icons, and bundled Gmsh documentation.
- Removed roughly 500 lines of unreachable code — an unused linear solver, unused mesh helpers, and dead file-handling routines. No change to behaviour.

## Compatibility Notes

- **Re-run concentration cases** produced before this version. Their transport balance applied density twice.
- **Re-run cases involving radial velocity, pressure outlets, or fully-developed inlets.** Those paths were corrected during this cycle.
- The "Pressure Correction" relaxation slider was removed from Advanced Options. It had no effect on the solve.
- Solver files written by very early alpha builds (format version 3) no longer load. Version 4 and later still do. Project files are unaffected.
- Binary file formats are still under development and may change again before a stable release.
- Linux support is experimental. MP4 export and image clipboard copying are not implemented there; PNG-sequence export works.
- The performance figures above describe one case on one GPU and are not a general benchmark.
